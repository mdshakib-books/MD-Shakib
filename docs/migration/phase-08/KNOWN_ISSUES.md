## 2. Non-Blocking Warnings & Technical Debt

### 2.1 Next.js Image Element Warnings (`@next/next/no-img-element`)
- **Affected Files:**
  - `apps/web/app/admin/books/AdminBooksClient.tsx` (line 362)
  - `apps/web/components/admin/MediaUploader.tsx` (line 185)
- **Warning Message:**
  `Using <img> could result in slower LCP and higher bandwidth. Consider using <Image /> from next/image or a custom image loader.`
- **Root Cause & Rationale:**
  - Both instances occur in the admin catalog manager where direct file input blobs or raw Cloudinary unsigned upload previews are rendered prior to saving to Supabase.
  - Next.js `<Image />` requires whitelisted remote hostname patterns in `next.config.ts` and does not optimize local temporary `blob:` URLs generated by the browser's `URL.createObjectURL(file)`.
- **Impact on Storefront:** Zero impact on customer storefront pages (`/`, `/books`, `/books/[id]`), which correctly use responsive layouts and optimized images.
- **Resolution Plan:** Can be transitioned to a custom Cloudinary loader component in a future administrative maintenance sprint.

### 2.2 Next.js Middleware File Convention Deprecation Notice
- **Build Log Notice:**
  `The "middleware" file convention is deprecated. Please use "proxy" instead. Learn more: https://nextjs.org/docs/messages/middleware-to-proxy`
- **Root Cause & Rationale:**
  - Next.js 16.4.3 introduced an automated codemod (`@next/codemod@canary middleware-to-proxy`) proposing to rename `middleware.ts` to `proxy.ts`.
  - The application's `middleware.ts` functions flawlessly with zero runtime errors across auth session management and route protection.
- **Impact:** Informational notice only; does not affect build output, security, or runtime performance.
- **Resolution Plan:** Recommend executing the codemod during the next major Next.js framework upgrade cycle.

## 3. Assistive Technology & Platform Specific Notes

### 3.1 Screen Reader Dynamic Combobox Announcement Variances
- **Behavior:** Certain older screen reader versions (e.g., legacy JAWS or NVDA pre-2022) do not automatically read `aria-activedescendant` changes if virtual cursor mode is locked.
- **Mitigation Implemented:** Added a secondary `role="status"` and `aria-live="polite"` notification container in `SearchBar.tsx` that explicitly outputs the count of matching suggestions (e.g., *"3 suggestions available. Use up and down arrows to navigate."*).

### 3.2 High-Contrast Mode & Windows Forced Colors
- **Observation:** In Windows Forced Colors Mode, custom SVG fills may be replaced by system button colors.
- **Mitigation Implemented:** All icon-only buttons include visible tooltips or unambiguous `aria-label`s, ensuring full clarity even when custom brand colors are overridden by OS contrast themes.

### 3.3 Test Environment Port Allocation
- **Note:** The automated verification test suite uses port `3001` (`http://localhost:3001`) with `--headless=new` Google Chrome CDP to guarantee zero collisions with developers running local development on default port `3000`. The test runner cleanly starts and terminates the server upon test completion.
